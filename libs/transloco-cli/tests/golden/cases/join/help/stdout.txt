Usage: transloco join [options]

Join the translation files of all scopes into one file per language

Options:
  --translations-path <dir>  The folder of the root translation files (defaults
                             to `rootTranslationsPath` of the config)
  -o, --out-dir <dir>        The folder the joined files are written to, it is
                             emptied first (default: "dist-i18n")
  --default-lang <lang>      The default language of the project (defaults to
                             `defaultLang` of the config)
  --include-default-lang     Join the default language as well, it is left out
                             otherwise
  -c, --config <path>        Path to a custom transloco config
  -h, --help                 Display help for the command
