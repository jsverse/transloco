Usage: transloco init [options]

Prepare the project for the CLI: write the config, create the translation files
and add the scripts

Options:
  -l, --langs <langs...>     The languages of the project (asked for when left
                             out)
  --translations-path <dir>  The folder of the translation files (asked for when
                             left out)
  --no-scripts               Don't add the i18n:extract and i18n:find scripts to
                             package.json
  -y, --yes                  Ask nothing: what was not given is `en` for the
                             languages, `src/assets/i18n` for the folder, and
                             the files and scripts are added
  --force                    Overwrite an existing transloco.config.ts
  -h, --help                 Display help for the command
