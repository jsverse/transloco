# Transloco Validator

> [!WARNING]
> The `transloco-validator` bin is superseded by `transloco validate` from `@jsverse/transloco-cli` and keeps working. It will be deprecated on npm in Transloco v10. The function this package exports is not part of the CLI, import it from `@jsverse/transloco-validator` as before.

Discover more about this plugin and how it can enhance your workflow in the [official Transloco documentation](https://jsverse.gitbook.io/transloco/tools/validator).
