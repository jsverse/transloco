# Transloco Optimize

> [!WARNING]
> `@jsverse/transloco-optimize` is superseded by `@jsverse/transloco-cli` and keeps working. It will be deprecated on npm in Transloco v10. Use `transloco optimize` from `@jsverse/transloco-cli` instead.

Discover more about this plugin and how it can enhance your workflow in the [official Transloco documentation](https://jsverse.gitbook.io/transloco/tools/optimize).
