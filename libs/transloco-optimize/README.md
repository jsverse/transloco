# Transloco Optimize

> [!WARNING]
> The `transloco-optimize` bin is superseded by `transloco optimize` from `@jsverse/transloco-cli` and keeps working. It will be deprecated on npm in Transloco v10. The `getTranslationFiles`, `getTranslationsFolder` and `optimizeFiles` functions are not part of the CLI, import them from `@jsverse/transloco-optimize` as before.

Discover more about this plugin and how it can enhance your workflow in the [official Transloco documentation](https://jsverse.gitbook.io/transloco/tools/optimize).
